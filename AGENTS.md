# Working on grove

- `core/` is the source of truth; `hosts/` and `.claude-plugin/marketplace.json` are generated by
  `scripts/build.py` and committed. Change `core/`, rebuild, commit both. `tests/run.sh` fails if they differ.
- The skill must match Leaf (https://github.com/AmozPay/leaf, usually checked out next to this repo): tool names, operation names, batch rules. The tests that take
  `LEAF_BIN_DIR` check this against real binaries; run them when either side changes.
- Never point a test or an experiment at `~/wiki` (the owner's wiki): use a temporary one
  (`LEAF_WIKI=/tmp/...`). Tests use stub programs or temporary wikis only.
- No network calls except the launcher's one-time, hash-checked download. Do not push or publish without the
  owner's go-ahead.
